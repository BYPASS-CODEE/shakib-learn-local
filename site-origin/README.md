# شکیب‌لرن

سامانهٔ فارسی، راست‌چین و مستقل آموزش و خدمات جامعهٔ داروسازی. برنامه در زمان اجرا برای لوگو، فونت، تصاویر آموزشی، کاتالوگ دوره‌ها یا فایل اندروید به shakiblearn.com / shakiblearn.ir وصل نمی‌شود. دارایی‌های موردنیاز و کاتالوگ محلی داخل همین پروژه‌اند.

## اجرا

```powershell
npm install
npm run dev
```

سایت روی `http://localhost:3200` و API محلی روی پورت `4173` اجرا می‌شود. SQLite به‌طور خودکار ۱۹ دورهٔ همراه پروژه را از `data/courses-seed.json` وارد می‌کند؛ تصاویر اصلی، گالری‌های دریافت‌شده و فونت IRANSansX نیز در `public/` نگه‌داری می‌شوند. برای بازنشانی یا آماده‌سازی کاتالوگ محلی:

```powershell
npm run catalog:seed
```

## آموزش و اپلیکیشن

دوره‌ها و معرفی‌های عمومیِ قابل‌دسترسی به‌صورت دادهٔ محلی نمایش داده می‌شوند؛ عکس‌های موجود در گالری هر دوره قابل دیدن‌اند. محتوای درس/ویدیو که در فایل‌ها یا دادهٔ مجاز مالک موجود نیست، جعل نشده است. درخواست ثبت‌نام در سامانه ثبت و برای مدیر قابل بررسی است؛ پرداخت دوره و دسترسی به ویدیوها تا اتصال سرویس و دریافت محتوای مجاز فعال نیست.

فایل اندروید از همین میزبان در `public/downloads/shakiblearn.apk` ارائه می‌شود. وب‌اپ همان سایت نصب‌پذیر است؛ برای استفاده از آن به وب‌سایت دیگری هدایت نمی‌شوید.

## ساخت و آزمون

```powershell
npm test
npm run build
```

مدیر اصلی را یک‌بار با گذرواژهٔ قوی بسازید:

```powershell
$env:ADMIN_EMAIL = "admin@example.com"
$env:ADMIN_PASSWORD = "یک-گذرواژهٔ-تصادفی-و-بلند-حداقل-۱۶-نویسه"
npm run admin:create
```

پنل مدیریت در مسیر عمومی یا نوار ناوبری نمایش داده نمی‌شود و API نیز نقش مدیر را بررسی می‌کند.

## موارد لازم پیش از انتشار عمومی

درگاه و روش دریافت پول، پیامک/ایمیل، تأیید مدارک، محتوا و مجوز درس‌ها/ویدیوها، اطلاعات دارویی و کالاهای فروشگاه باید با داده و دسترسی رسمی کارفرما تنظیم و در میزبان نهایی آزمایش شوند. قیمت‌های دوره، ظرفیت و زمان‌بندیِ واردشده عین اطلاعات عمومیِ قابل‌دسترس هنگام انتقال‌اند؛ پیش از فروش دوباره تأییدشان کنید. نام دامنهٔ قطعی نیز باید در sitemap و تنظیمات میزبانی ثبت شود.
